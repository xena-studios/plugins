# Getting help

- **How do I…?** The [docs](https://docs.xenastudios.co) cover setup, commands, permissions and every config option.
- **Bugs and feature requests:** open an [issue](https://github.com/xena-studios/plugins/issues/new/choose). Include the plugin and its version (`/<plugin> info`), your server software and version, and any console errors.
- **Security problems:** see [SECURITY.md](SECURITY.md). Never a public issue.
- **Anything else:** email [contact@xenastudios.co](mailto:contact@xenastudios.co).
