# Getting help

- **How do I…?** The [docs](https://docs.xenastudios.co) cover setup, commands, permissions and config.
- **Bugs and ideas:** [open an issue](https://github.com/xena-studios/plugins/issues/new/choose). Include the plugin version (`/<plugin> info`), your server software and version, and any console errors.
- **Security problems:** follow [SECURITY.md](SECURITY.md), never a public issue.
- **Anything else:** [contact@xenastudios.co](mailto:contact@xenastudios.co).
