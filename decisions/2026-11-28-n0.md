# N0: NeoSkript's spike, and what it changes for N1 and N2 (2026-11-28)

NeoSkript's N0 (#202) tried the risky parts of its rewrite before converting anything. The results are in `sandbox/n0/`. What was decided from them, in addition to decisions/2026-11-27-neoskript-joins-the-rewrite.md:

- **Scripts are compiled to Java 8 class files on every server.** The spike's flag (`-Dneoskript.compiler.target=8`) defines each script class through a class loader of its own and keeps constants in static fields, in place of hidden classes and dynamic constants, and cost nothing measurable on Java 21. One output is one path to test, so N1 makes it the only one rather than choosing by the server's Java. A check that generated code calls only Java 8's API runs on every pull request from N1. What it changes for owners: script lines appear in stack traces.
- **The frontend goes straight into shared code in N1,** not JVM-first: jvm, wasmWasi (Pumpkin) and **wasmJs for the website**, not Kotlin/JS, whose regex gets Skript's patterns wrong. This corrects the earlier decision, which said wasmWasi for the website. TeaVM stays until the converted frontend passes its tests on wasmJs.
- **The frontend gets a nesting limit of its own.** Wasm can't catch a stack overflow, and the frontend catches `StackOverflowError` in three places today, so a deep script would crash the checker there. A limit keeps "no script can crash it" true on every target.
- **Case-insensitive patterns match lower-cased text.** Kotlin's `IGNORE_CASE` folds letters outside ASCII on the JVM, which Java's doesn't, so `1 ſecond` would read as a time period. Lower-casing and matching exactly keeps Skript's answer on every target.
- **The game model is the platform's own objects and neutral operations on them.** No wrapper per value: compiled code already holds values as `Object`, Skript add-ons on Bukkit keep getting Bukkit's objects, and the cost was within the noise on Paper and a few nanoseconds a call on Fabric. Kinds of block, item and entity are one type per modern id, with generated tables for older versions.
- **The model's shared half goes into the core in N2,** built with the plugins that need it: type tables by id (xMarket's legacy item table is the start), blocks by place, entity basics (location, teleport, health, type), one `WorldRef` per world, and which thread owns a value. Events, their values, Skript's types and behaviour, and the add-on bridge stay NeoSkript's. On Paper and Folia, Bukkit's events stay the event objects.
- **No separate ASM download.** ASM is about 130 KB of the 2.2 MB jar; one jar per platform and R8 are where the size is, in N2.

Found on the way, for the core (not NeoSkript's to fix): `BukkitRefs.ref` and Fabric's `Level.ref` make a new `WorldRef` on every call, and on Fabric 1.21.11 a player's quit arrives on a network thread and `FabricPlatform` fires its `PlayerQuitEvent` there.
