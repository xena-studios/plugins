# xUtilities on Sponge: everything but the workstations, and two calls looked up by shape (2026-11-28)

xUtilities' Sponge adapter (`xutilities/sponge`, M16, #134), the first plugin on platform-sponge ([2026-11-28-platform-sponge.md](2026-11-28-platform-sponge.md)). It's in 3.0.0, the unreleased version, as every M16 platform build is ([2026-11-28-neoforge-and-forge.md](2026-11-28-neoforge-and-forge.md)).

- **What it does is SpongeAPI's data keys and inventories:** game mode, flight, speed, health, hunger, fire and effects through `Keys`; `/repair` through each slot's durability; `/clear` on the primary inventory, or all of it; `/enderchest` the owner's own inventory; `/trash` a custom four-row chest; `/top` from the world's motion-blocking height, or below the roof in a world with one; sounds through Adventure's `Sound`, which the player is an audience for.
- **No workstation menus.** A Sponge custom inventory of an anvil's or a crafting table's shape has none of its logic, and SpongeAPI has no way to open the real one without its block, so each station command says so, as Bukkit's do where the server can't (`Features.stations`). They come back if SpongeAPI gets one.
- **`/back` hears deaths and xUtilities' own teleports**, as on Fabric (`teleportEvents` off): Sponge's move event fires for every step a player takes, which `/back` doesn't need and the idle budget wouldn't want.
- **Harmful effects are vanilla's list, by key:** SpongeAPI's effect types don't say which are harmful (Minecraft's `MobEffectCategory`), so `/heal` removes the vanilla effects in that category, by id.
- **Two calls changed shape after API 8 and are looked up once, by shape:** a slot's `set` takes an `ItemStackLike` from API 17 (an `ItemStack` is one), and a player's latency moved from `connection().latency()` to `connectionState().latency()`. A third, `ViewableInventory.Builder.EndStep.build()`, changed its return type in API 17, so `/trash` calls the erased `Builder.build()` both have. `checkApiNewest` found all three.
- **The jar is 815 KiB** (budget 900), over the 500 KiB target because the Kotlin stdlib and the YAML parser are inside, as on every Sponge jar.
- Booted with its console checks on SpongeVanilla 1.16.5 (API 8, Java 17) and 26.3 (API 21, Java 25) in CI; by hand, a mineflayer player ran `/gmc`, `/fly`, `/speed`, `/heal`, `/feed`, `/ping`, `/repair`, `/top`, `/setrotation`, `/clear`, `/trash`, `/enderchest`, `/gms`, `/back` and `/xutilities info` on 1.16.5 and 1.21.10 (API 17), each answering, the menus opening, nothing logged.
