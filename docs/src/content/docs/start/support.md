- **Bugs and feature requests:** open an issue on [GitHub](https://github.com/xena-studios/plugins/issues). Include the plugin and its version (from `/xutilities info`, `/zchat info` or `/xlimbo info`), your server software and version, and any console errors.
- **Anything else:** email [contact@xenastudios.co](mailto:contact@xenastudios.co).

Found a mistake in these docs? Every page has an **Edit page** link at the bottom.
