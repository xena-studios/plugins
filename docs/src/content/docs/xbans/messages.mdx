Every message is in `plugins/xBans/lang/` (`plugins/xbans/lang/` on Velocity, `config/xbans/lang/` on Fabric), one file per language: `en.yml`, `de.yml`, `es.yml`, `fr.yml`, `pt-BR.yml`, `ru.yml`, `pl.yml` and `zh-CN.yml`. Edit any of these files in place and run `/xbans reload`: your edits are kept, and a message you haven't edited gets the new text when an update changes it. Delete a file to have it written again as shipped. A blank message (`""`) sends nothing.

The ban and kick screens (`screens.*`) and the broadcasts (`broadcasts.*`) are messages too, drawn in the punished player's language: a ban screen in the language they last played in, as the family's player cache remembers it. A message can use [the theme's tags](/xbans/configuration/#make-it-look-like-your-server) (`<prefix>`, `<highlight>`, `<success>`, `<error>`), any [formatting](/start/formatting/), and the placeholders listed beside it. Every message about a punishment can use all of a punishment's placeholders (`<id>`, `<reason>`, `<staff>`, `<expires>`, `<time-left>`, `<appeal>` and the rest), whichever its English uses. The `core.*` messages are the ones every Xena plugin shares: errors such as "You don't have permission", and the replies of `/xbans reload` and `/xbans debug`.

:::note[The translations are drafts]
The seven languages besides English were drafted by machine translation and haven't been read by native speakers yet. Corrections are welcome: open an issue or a pull request with the file.
:::
