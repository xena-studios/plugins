The config is `plugins/xLimbo/config.yml`, written on first start. Apply changes with `/xlimbo reload`: everything applies, including `/join`'s aliases. Changing the world's `name`, `floor-block` or `floor-y` [rebuilds the world](/xlimbo/world/#changing-the-world). A bad value falls back to its default with a warning in the console; xLimbo never stops over config. Every setting 2.x had is where it was; the messages are in [`lang/`](/xlimbo/messages/).

| Section | What it covers |
| --- | --- |
| `messages` | The language and the theme, `shared` with every Xena plugin unless set here. |
| `world` | The void world, its floor, border and distances: [The world](/xlimbo/world/#the-world). |
| `player`, `join`, `quit`, `death`, `action-bar` | What arriving players get and see: [Arriving players](/xlimbo/world/#arriving-players). |
| `main-server`, `auto-join`, `server-check`, `queue` | Where players go back to, and sending them back on their own: [Network setup](/xlimbo/network-setup/). |
| `send-back` | New in 3.0: through the proxy (`proxy`, as always) or with a teleport on this server (`teleport`): [On one server](/xlimbo/on-one-server/). |
| `join-command` | `/join`'s aliases, permission and cooldown: [Commands](/xlimbo/commands/). |
| `protections` | What's blocked: [Protections](/xlimbo/protections/). |
| `updates` | The update checker: [Privacy](/start/privacy/). |
