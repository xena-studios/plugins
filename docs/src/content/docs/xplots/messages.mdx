Every message is in `plugins/xPlots/lang/`, one file per language: `en.yml`, `de.yml`, `es.yml`, `fr.yml`, `pt-BR.yml`, `ru.yml`, `pl.yml` and `zh-CN.yml`. Edit any of these files in place and run `/xplots reload`: your edits are kept, and a message you haven't edited gets the new text when an update changes it. Delete a file to have it written again as shipped. A blank message (`""`) sends nothing.

Each player reads xPlots in their client's language: chat, menus, and the wand. Signs are the same for everyone, so they're in the server's language (`messages.language`). `signs.*` are four lines each and a menu button's `lore` its lines, split with `<newline>`. A message can use [the theme's tags](/start/formatting/#the-theme) (`<prefix>`, `<highlight>`, `<success>`, `<error>`), any [formatting](/start/formatting/), and the placeholders listed beside it. The `core.*` messages are the ones every Xena plugin shares.

:::note[The translations are drafts]
The seven languages besides English were drafted by machine translation and haven't been read by native speakers yet. Corrections are welcome: open an issue or a pull request with the file.
:::
