**Every command you need. None you don't.**

xUtilities gives every server the small commands it needs, whatever kind of server it is: gamemodes, flight, speed, `/top`, `/back`, heal and feed, inventory tools, workstation menus, and link commands like `/discord` that you write yourself. Install it on your lobby, survival and minigame servers alike, then switch off whatever a server doesn't use.

- **Every command can be turned off**, renamed with aliases, given its own permission, and reworded. A disabled command isn't registered at all, so it doesn't show up in tab completion.
- **Next to nothing to run.** No repeating tasks. The only event listener is `/back`'s, and it exists only while `/back` is on.
- **Paper and Folia**, from the same jar.

Current version: **1.0.1**, for Paper 1.20.6 or newer and Java 21. [Download on Modrinth](https://modrinth.com/plugin/xutilities).
