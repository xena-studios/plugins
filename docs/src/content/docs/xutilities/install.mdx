On the first start xUtilities writes `config.yml` and one file per language in `lang/`, in `plugins/xUtilities/` (Bukkit) or `config/xutilities/` (Fabric, NeoForge, Forge and Sponge). Settings every Xena plugin shares, such as the language and the look of messages, are in `plugins/Xena/config.yml` (`config/xena/` on Fabric, NeoForge, Forge and Sponge).

## Coming from 2.x

Replace the jar and restart: see [Upgrading from 2.x](/xutilities/upgrade/). The [2.x docs](/xutilities/v2/) stay up while 2.x gets fixes.
