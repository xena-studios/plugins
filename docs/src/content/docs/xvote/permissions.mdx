1.x's: `xvote.use` (`/vote`, `/vote top`, `/vote claim`) is everyone's; `xvote.test` and `xvote.admin` (`status`, `key`, `token`, `import`, `party`, and every admin subcommand) are operators'. Each admin subcommand also has its own, `xvote.admin.<subcommand>`. On the proxies, the proxy's own permissions (LuckPerms on the proxy) answer for `/xvoteproxy`.
