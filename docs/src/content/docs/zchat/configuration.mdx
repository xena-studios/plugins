The config is `plugins/zChat/config.yml` (`config/zchat/config.yml` on Fabric, NeoForge and Forge), written on first start. Apply changes with `/zchat reload` (or `/zc reload`): everything applies, including turning commands on or off and changing aliases and permissions. A bad value falls back to its default with a warning in the console; zChat never stops over config. The chat formats are here; zChat's own messages are in `lang/`: see [Messages](/zchat/messages/).

| Section | What it's for |
| --- | --- |
| `messages` | The language and the theme, `shared` with every Xena plugin unless set here. |
| `formatting` | Formats per group, the fallback format, and the colour permission: [Chat formats](/zchat/formats/). |
| `filter` | Words and patterns to censor or block, and `/filter`: [Moderation](/zchat/moderation/#filter). |
| `cooldown`, `anti-repeat` | Time between messages, and repeated messages: [Moderation](/zchat/moderation/). |
| `mentions` | Highlighting and pinging named players: [Mentions](/zchat/mentions/#mentions). |
| `clearchat`, `mutechat`, `togglechat` | Each command's switch, aliases and permission: [Moderation](/zchat/moderation/). |
| `private-messages` | `/msg`, `/reply` and `/socialspy`: [Private messages](/zchat/mentions/#private-messages). |
| `updates` | The update checker. |

## Make it look like your server

`messages.theme` sets the look of every message zChat sends, and the tags chat formats may use: a prefix, the text colour, and three styles. Each is `shared` until you set it, which takes the value every Xena plugin shares, in `plugins/Xena/config.yml`: set it there to restyle the whole family, or here for zChat alone.

```yaml
messages:
  theme:
    prefix: "<dark_gray>[<gradient:#B48CFF:#5EE08A>MyServer</gradient>]</dark_gray> "
    highlight: "<gold>"
```

## Language

`messages.language` is `auto` by default (through `shared`): each player reads zChat's messages in their client's language, and the console in `default-language`. Set it to one language, such as `language: en`, to give everyone the same. A config carried forward from 3.x with messages you'd edited is set to `en`, so your words are what everyone sees, as before.
