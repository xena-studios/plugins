# Imports from LiteBans' H2 file and AdvancedBan's HSQLDB files on a real server (boot.sh seeds
# them from import-seed/, written by the drivers those plugins ship: H2 1.4.199 and HSQLDB 2.4.0,
# by ./gradlew :xbans:common:jvmTest -PupdateBootSeed). Neither plugin is installed, as after an
# owner takes its jar out. The driver each needs is downloaded into plugins/Xena/libraries/ (a
# pinned on-demand library) and let go afterwards; a second import adds nothing.

expect: Imported 0 punishments from LiteBans (5 already there).
