# xMoney on a real server, from the console. CI boots it on its own, beside two
# never-released plugins that use it as Vault (vault-consumer and hook-consumer): with
# xMoney installed every plugin sees Vault, and the sandbox checks the core's Vault hook
# on a server without one. The database opens with the SQLite driver Paper and Folia ship.
logged: Loaded 0 accounts from the SQLite database money.db.
logged: VAULT CONSUMER found xMoney
run: xmoney info
expect: xMoney 1.0.0 on

# A plugin.yml plugin that depends on Vault: Vault 1 and VaultUnlocked 2, from other
# threads, for players who never joined, by name, and with NaN, negative and huge amounts.
run: vaulttest
expect: VAULT TEST PASS
# A Paper plugin charging through the core's Vault hook, as xPlots and xTeleport do.
run: hooktest
expect: HOOK TEST PASS

# Without a permissions plugin, Vault's Permission API still has a provider, as with real Vault.
run: vaultperms
expect: VAULT PERMISSION SuperPerms

# The commands, on the accounts those made. VaultTestBank is a town-style account by name.
run: baltop
expect: Richest players.
run: balance VaultTestBank
expect: VaultTestBank's balance: $50.00
run: eco give VaultTestBank 25
expect: Gave VaultTestBank $25.00. They have $75.00.
run: eco take VaultTestBank 1000
expect: VaultTestBank only has $75.00.
run: eco set VaultTestBank 10.5
expect: Set VaultTestBank's balance to $10.50.
run: eco history VaultTestBank
expect: History of VaultTestBank: 3 changes
# A name nobody has played under is looked up (offline uuid here) and refused.
run: eco give Nobody_Here_12 5
expect: Nobody_Here_12 has never played here.

# Imports: the old economy vault-consumer registers, and plugins that aren't installed.
run: xmoney import vault
expect: Nothing to import from OldEconomy
run: xmoney import essentials
expect: there's no plugins/Essentials/userdata folder.
run: xmoney import cmi
expect: there's no plugins/CMI/cmi.sqlite.db.

run: xmoney reload
expect: Reloaded xMoney in
run: xmoney status
expect: Problem: none
