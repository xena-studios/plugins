# xPlots on a real server, from the console. Paper only: xPlots doesn't run on Folia.
# The database opens with the SQLite driver Paper ships, from a paper-plugin.
paper logged: Loaded 0 fields with 0 plots from the SQLite database plots.db.
paper run: xplots info
paper expect: xPlots 1.0.1 on

# A field from a typed selection: two 5×5 plots with a 2-block path, each with its sign.
paper run: forceload add 192 192 223 223
paper expect: Marked
paper run: xplots select world 200 64 200 211 70 204
paper expect: Selected
paper run: xplots field create boot size:5 path:2
paper expect: = 2 plots of
paper run: xplots confirm
paper expect: Made field boot
paper run: execute if block 200 65 205 #minecraft:standing_signs run say SIGN PLACED
paper expect: SIGN PLACED

paper run: xplots field set boot price 250
paper expect: Set boot's price to 250
paper run: xplots plot info boot-2
paper expect: free.
paper run: xplots plot setowner boot-1 Steve
paper expect: has never played here.

# Reloading keeps every plot.
paper run: xplots reload
paper expect: Reloaded xPlots in
paper run: xplots field list
paper expect: 0 of 2 rented

# Deleting asks first, then takes the signs down.
paper run: xplots field delete boot
paper expect: Delete boot
paper run: xplots confirm
paper expect: Deleted boot
paper run: execute if block 200 65 205 minecraft:air run say SIGN GONE
paper expect: SIGN GONE
