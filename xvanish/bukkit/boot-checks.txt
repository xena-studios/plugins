# xVanish on a real Bukkit-family server, from the console (scripts/boot-test.sh --checks,
# through boot.sh): every command that runs without a player, answered by the core's dispatcher
# and drawn from lang/en.yml, the import's dry run and run from SuperVanish's data.yml (seeded
# from import-seed/), forget, a reload, debug, and a clean stop. No database: a single server
# keeps who's vanished in vanished.txt.
logged: xVanish 1.0.0 on
run: xvanish info
expect: xVanish 1.0.0 on
run: vanish list
expect: Nobody is vanished.
# The console can't vanish itself, and finds no one by a name nobody has.
run: vanish
expect: Only players can use this command.
run: vanish on Nobody
expect: No player called Nobody is online.

# SuperVanish's vanished players, into vanished.txt: a dry run first, then for real.
run: xvanish import supervanish --dry-run
expect: Dry run from SuperVanish: 2 of 2 records would be imported
run: xvanish import supervanish
expect: Imported from SuperVanish: 2.
run: xvanish import premiumvanish
expect: There's no PremiumVanish data here to import.
run: xvanish forget 0f7c3c58-6d4c-4f0e-9f7a-2a1b3c4d5e6f
run: xvanish forget 0f7c3c58-6d4c-4f0e-9f7a-2a1b3c4d5e6f
expect: Forgot

# Reloading keeps everything running: every switch's listener comes back.
run: xvanish reload
expect: Reloaded xVanish
run: xvanish debug
expect: Modules:
expect: Debug report saved as debug/debug-
