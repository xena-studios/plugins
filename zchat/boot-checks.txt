# zChat on a real server, from the console.
run: zchat info
expect: zChat 3.1.2 on

# Ours replaces Minecraft's /msg (vanilla says "No player was found").
run: msg Nobody hi
expect: No player named Nobody is online.
run: tell Nobody hi
expect: No player named Nobody is online.

# The console may use selectors (Paper only); with nobody online, none match.
paper run: msg @a hi
paper expect: No player named @a is online.

run: mutechat
expect: Chat has been muted by
run: mutechat
expect: Chat has been unmuted by
run: clearchat
expect: Chat was cleared by

# /filter saves to config.yml and applies at once (the edit runs on the next tick).
run: filter add bootcheck*
expect: Added bootcheck* to the filter.
run: filter test say bootchecks now
expect: That would show as: say ********** now
run: filter remove bootcheck*
expect: Removed bootcheck* from the filter.
run: filter test say bootchecks now
expect: That passes the filter.

# Reloading re-registers commands while the server runs.
run: zc reload
expect: Reloaded zChat in
run: msg Nobody hi
expect: No player named Nobody is online.

# A datapack reload rebuilds the server's command tree; ours must survive it.
paper run: minecraft:reload
paper expect: advancements
paper run: msg Nobody hi
paper expect: No player named Nobody is online.
